# Python dependencies

Tested with Python 3.12. The analysis uses these pinned package versions:

| Package | Version | Purpose |
|---|---:|---|
| NumPy | 2.5.4 | Array and matrix operations |
| pandas | 3.0.6 | Dataset loading and result tables |
| scikit-learn | 1.9.1 | Standardization and optimal linear regression |
| statsmodels | 0.15.0 | OLS inference and p-values |
| Matplotlib | 3.11.2 | Figures |
| openpyxl | 3.1.5 | Excel workbook support |
| xlrd | 2.0.2 | Reading the supplied `.xls` workbook |

Install the packages from a terminal with:

```bash
python -m pip install numpy==2.5.4 pandas==3.0.6 scikit-learn==1.9.1 statsmodels==0.15.0 matplotlib==3.11.2 openpyxl==3.1.5 xlrd==2.0.2
```
